# PodBattery releases

Release APKs for **PodBattery**, a minimal Android app and home-screen widget that shows AirPods left, right and case battery levels from their Bluetooth broadcasts. It needs Android 12 or newer.

The source code is in a separate private repository. This repository holds only the release builds.

## Install

Download the latest `PodBattery-vX.Y-debug.apk` from [Releases](https://github.com/gh00ul/PodBattery-releases/releases/latest) and open it on your phone. Allow installs from that source if Android asks.

## Updates

From v1.3, PodBattery checks this repository's latest release when you open the app. If there is a newer one, tap **Install vX.Y.Z**. The app downloads the APK and Android asks you to confirm the update.
